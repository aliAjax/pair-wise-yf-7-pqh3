# 活字排版工坊 · 稿件连排台

纯前端本地应用，直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据只存浏览器 localStorage，刷新后保留。

## 稿件连排台（新增）

把整篇稿件按纸张与横竖排逐字排入版页：

- **预置稿样**：三篇含书名号《》、句号。、省略号……的稿样（另有破折号——、引号“”），一键载入。
- **逐字排入**：按纸张（明信片 16×10 / 书签 7×18 / 方形小笺 12×12）与横排、竖排逐字落格；省略号、破折号两两成组，绝不拆分跨行。
- **行禁则**：行首不出现收束标点（。，》”……），行尾不悬开启标点（《“（……）；冲突时整字回退重排，回退无解才允许收束标点悬挂行尾并记警告。
- **分页**：整页排满才另起版页；排版保留原字序和全部字符，校验逐字比对原稿。
- **确认流**：排版结果先为「待确认」，可确认生效或拒绝重排——拒绝时原版页与草稿不变。
- **快照**：已确认版面改一字即退回校验，并自动留下上一版快照，可随时恢复。
- **业务拆分**：`typesetting-rules.js`（排版规则）、`composer-store.js`（版页状态）、`composer-ui.js`（界面接入）。

## 活字排版工坊（原有）

维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出 PNG 预览图（`app.js`）。
