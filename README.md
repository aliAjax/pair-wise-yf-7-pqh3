# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 稿件连排台

在工坊下方新增的整稿连排功能：

- 预置含书名号《》、句号。、省略号……的稿样，可一键载入。
- 按纸张（明信片 / 书签 / 方形小笺）与横竖排逐字排入：行首不出现收束标点，行尾不悬开启标点，省略号等连字符号不拆行；冲突时整字回退重排，一页排满才另起版页。
- 排版保留原字序与全部字符；校验不过则拒绝，原版页与草稿不变。
- 已确认版面改一字即退回待校验，并自动留上一版快照（可恢复）。
- 代码拆分为三个业务文件：`typeset-rules.js`（排版规则）、`typeset-store.js`（版页状态）、`typeset-ui.js`（界面接入）。
- 数据只存浏览器 localStorage，刷新保留。
